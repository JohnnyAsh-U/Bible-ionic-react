# Bible EN/FR

A cross-platform Bible application built with **Ionic React**, providing English and French scripture reading with bookmarking, search, and an interactive scripture game.

## ✨ Features

* 📖 **Bible Reading** — Read Bible scriptures in English and French.
* 🌍 **English & French** — Switch between the two supported languages.
* 🔖 **Bookmarks** — Save scriptures for quick access later.
* 🔎 **Scripture Search** — Quickly find scriptures by text or reference.
* 🎮 **Scripture Game** — Test your knowledge by identifying a scripture from multiple options.
* 📱 **Cross-platform** — Built with Ionic React for mobile and web environments.
* ⚡ **Fast navigation** — Designed for a smooth reading and browsing experience.

## 🎮 Scripture Game

The application includes an interactive game based on bookmarked scriptures.

A scripture is presented to the player along with multiple possible scriptures. The player must select the correct one.

This creates a simple way to turn Bible study into an interactive experience while making use of the user's own bookmarked scriptures.

## 🏗️ Application Structure

The application is organized around several core features:

```text

│   └── French Scriptures
│
├── Search
│   └── Scripture search
│
├── Bookmarks
│   └── Saved scriptures
│
└── Scripture Game
    ├── Select bookmarked scriptures
    ├── Generate questions
    └── Multiple-choice answers
```

## 🎯 Purpose

The project started as an exploration of building a practical cross-platform application with React and Ionic.

Beyond Bible reading, the goal was to experiment with combining traditional content browsing with interactive features such as bookmarking, search, and gamification.
